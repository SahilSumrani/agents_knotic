Agent loop

Six steps. One decision. Real side effects.

GitHub → risk score → Netlify deploy or Jira hold → fetch this page → rollback if broken → Notion report. Four integrations, zero vendor SDKs.

  1. 01

    Ingest

    Commits, diffs, CI signals, and PRs from GitHub.

  2. 02

    Assess

    Features + Groq verdict. Heuristic floor so shipping stays honest.

  3. 03

    Act

    Hold with a Jira ticket, or trigger a real Netlify build.

  4. 04

    Verify

    Poll deploy state, then GET this page for the marker above.

  5. 05

    Heal

    Restore a good deploy, re-check production, file a Jira incident.

  6. 06

    Report

    Append the release or incident write-up to Notion.
